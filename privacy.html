Privacy policy

Effective October 27, 2026.

rclone Google Drive is a personal connection operated by michaelvstevens88 to access their own Google Drive using rclone on their computer.

Google data access and use

The connection uses Google authorization to list, read, upload, update, and delete files as directed by its owner. File data and metadata are used only to provide the requested Drive access and file operations.

Storage and sharing

Authorization credentials and local file caches are stored on the owner’s computer. Drive files remain in Google Drive unless the owner downloads, changes, or deletes them. This personal connection does not sell Google user data or disclose it to advertisers. File transfers occur between the owner’s computer and Google.

Control and deletion

The owner can revoke the connection in their Google Account’s third-party access settings and remove local credentials and cached files from their computer. Revoking access does not itself delete files in Google Drive.

This website

These informational pages do not request Google sign-in or contain Drive files. They use no custom analytics or tracking scripts. GitHub Pages hosts this website and may process standard technical request information under GitHub’s privacy statement.
